# Benchmark plan

The repository includes a Locust load-test surface. Measure p50/p95/p99 latency, throughput, error rate, concurrency, dependency latency and resource saturation.

Run representative workloads before changing SLO targets. Capture the exact source revision, workload shape, concurrency, environment and dependency configuration so results are reproducible.

Do not treat local benchmark numbers as production SLO evidence.
