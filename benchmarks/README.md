# Benchmark Evidence

Use this directory for reproducible performance measurements.

## Required record
- Commit SHA
- Workload
- Dataset/model/index version
- Environment
- Configuration
- Throughput
- p50 latency
- p95 latency
- p99 latency
- Error rate
- CPU/memory (when relevant)
- Baseline
- Change
- Result
- Reproduction command

Never enter fabricated measurements.
